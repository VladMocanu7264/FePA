Abstract

This document provides an overview of the Paw Alert web application, including its main features and how to use it. The application allows users to create, view, and filter posts about unsupervised animals in their area.

Introduction

Paw Alert is a web application designed to help users report and track unsupervised animals in their vicinity. This documentation provides detailed information on how to navigate and use the application.

Structure

The application is divided into several main sections, including the landing page, main page, post creation, post details, and user authentication.

Main Content

The main content section includes detailed information on the core functionalities of the application, such as creating and viewing posts, filtering posts by tags, and user authentication.

Landing Page

The landing page serves as the entry point to the application, providing links to the login and signup pages.

Main Page

The main page allows users to filter posts by tags and view a list of all posts. The left side of the page contains the filter form, and the right side displays the posts.

Post Creation

Users can create new posts by providing a title, description, image, and selecting the location on a map. The post creation form ensures that all necessary information is provided before submission.

Post Details

Each post has a details page that displays the title, image, description, tags, comments, and the location on a map. Users can add comments to posts using AJAX without refreshing the page.

User Authentication

The application includes user authentication features, allowing users to sign up, log in, and log out. The user's profile image is displayed in the header once logged in.

References

This section includes references to external libraries and resources used in the application, such as Leaflet.js for maps, Select2 for enhanced select elements, and Firebase JWT for user authentication.
